# Provenance

This repository is the standalone Docker-only LocalAIDocker project. Its Git
history starts at the point this boundary was created; it does not claim
continuity with any parent repository or with another LocalAI implementation.

Runtime data, model artifacts, deployment receipts, logs, evidence, backups,
and secrets are deliberately excluded from the source history by `.gitignore`.
They remain target-local when generated by the launcher.
